# SintaxeWear

Bem-vindo ao projeto SintaxeWear, um site de e-commerce com foco em experiência de navegação, identidade visual moderna e apresentação de produtos de forma elegante e intuitiva.

## Sobre o projeto

A SintaxeWear é uma loja virtual desenvolvida para oferecer uma interface limpa, responsiva e atrativa para clientes que desejam explorar produtos com facilidade. O projeto foi estruturado com foco em performance, organização de estilos e uma experiência de uso agradável em diferentes dispositivos.

## Objetivo

O objetivo principal deste projeto é apresentar o catálogo da marca de forma profissional, proporcionando:

- uma navegação simples e intuitiva;
- uma interface visual moderna;
- um layout responsivo para desktop e mobile;
- uma base sólida para expansão futura com páginas de produto, carrinho e checkout.

## Funcionalidades

O site já contempla, ou pode contemplar no futuro, os seguintes recursos:

- header fixo e estilizado;
- navegação entre páginas ou seções;
- layout responsivo;
- estrutura preparada para evolução em direção a um e-commerce completo;
- organização modular de estilos para facilitar manutenção.

## Tecnologias utilizadas

Este projeto foi desenvolvido com tecnologias web básicas:

- HTML5
- CSS3
- JavaScript (se aplicável em futuras melhorias)
